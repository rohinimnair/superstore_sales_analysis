📊 Superstore Sales Analysis — Mini Project

This is a beginner-level data analysis project built using Microsoft Excel to explore and visualize business performance in a fictional retail dataset called **Superstore**. The goal of this project was to practice using **Pivot Tables**, **Charts**, and basic analytics skills to gain insights from sales and profit data.

🧠 Project Overview

This report investigates:
- Sales and profit by **region**
- Sales by **product category**
- Profit distribution by **region**
- Sales volume by **shipment method**

The analysis helps identify performance trends across regions, categories, and logistics strategies.

🔧 Tools & Technologies

- **Microsoft Excel**
  - Pivot Tables
  - Column and Bar Charts
- **Dataset:** `Sample - Superstore.xlsx` (public dataset from Tableau)
- **Documentation:** Written in Microsoft Word (`.docx`) format

📈 Key Insights

- The **West** region had the highest sales.
- **Technology** was the top-selling product category.
- The **East** region showed the highest profit overall.
- **Standard Class** was the most frequently used shipment method.
