## Project Overview
This mini project analyzes key sales and profit patterns in a fictional retail dataset (*Superstore*) using Microsoft Excel Pivot Tables and Charts. The goal is to identify performance trends across regions, product categories, and shipment methods — essential business metrics for data analysts and business decision-makers.

The project showcases beginner-level data analysis skills including data summarization, visualization, and interpretation of business insights.

## Analyses & Insights

### 1. Sales by Region
- **Chart Type:** Clustered Column Chart  
- **Insight:** The West region generated the highest sales, followed by East and Central. The South region performed the lowest.

### 2. Sales by Category
- **Chart Type:** Pie Chart  
- **Insight:** Technology had the highest sales volume, followed by Office Supplies and Furniture.

### 3. Profit by Region
- **Chart Type:** Clustered Bar Chart  
- **Insight:** Although the West had the highest sales, the East region yielded the highest profits. The South region reported the lowest profit.

### 4. Sales by Shipment Method
- **Chart Type:** Line Graph  
- **Insight:** The 'Standard Class' shipment method was the most used, contributing the most to total sales. Other methods like First Class and Second Class followed.
